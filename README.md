# AGG_Public

Public AGG repository.

## Scope

This repository is intended for material that is safe to publish openly.
Review all inbound additions and outbound releases to ensure they are
appropriate for public distribution.

## Protection

- Do not commit secrets, private keys, credentials, or non-public data.
- Use `.gitignore` to keep local artifacts and sensitive local files out of the
  repository.
- Report suspected vulnerabilities privately according to
  [`SECURITY.md`](SECURITY.md).
