# Security Policy

## Supported content

This public repository should only contain material that is approved for public
release and covered by the repository license.

## Reporting a vulnerability

If you discover a security issue, do not disclose it publicly in an issue,
discussion, or pull request.

Instead, report the issue privately to the repository maintainers with:

- a description of the issue
- the affected files or paths
- steps to reproduce or validate the concern
- any suggested mitigation

Until maintainers confirm otherwise, treat suspicious content, credentials, and
private data exposure as security incidents and remove them from public changes.
